# Provenance, third-party notices, and reuse status

Confetti Blocks is an independently named 8×8 block-placement puzzle. It is not affiliated with or endorsed by the publishers of other block-puzzle games. No trademark, trade-dress, patent, or jurisdiction-specific legal clearance is represented here. The game name must be reviewed before broad marketing or monetization.

## Asset record

- HTML, JavaScript engine, application code, and CSS were created with AI assistance in this repository, then reviewed and modified through the recorded Git history.
- The favicon and mascot are programmatically authored SVG geometry. The PNG install icons were generated programmatically from simple rounded rectangles; no downloaded image assets are bundled.
- Sounds are local Web Audio oscillator sequences, not recordings, samples, or imported soundtracks.
- Typography uses the player's system fonts. No web fonts or third-party runtime assets are distributed.
